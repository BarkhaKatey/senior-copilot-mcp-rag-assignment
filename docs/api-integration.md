# API Integration

The simulator implements the supplied Postman contract, including Bearer authentication, asset search, metadata, alarms, summary, trends, correlation, flood analysis, rationalization, priority scoring, recommendations, calculation endpoints and KPI definitions.

Default token: `demo-token` (local demo only; replace via environment variables).

Trace headers supported: `trace_id`, `x-client-id`, `x-metadata-tag`.

The source collections are preserved under `postman/` for validation.
